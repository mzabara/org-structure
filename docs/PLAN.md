# PLAN — дорожная карта

Правила:
- Один человек (+ его агент) берёт один срез, пишет в строке «Владелец» своё имя и создаёт ветку `slice/<номер>-<имя>`.
- Срез вертикальный: БД → API → UI → проверка. Срез не закрыт, пока не пройдены пункты ACCEPTANCE.
- Закрытый пункт: `[x]`, в конце — хэш коммита.
- Срезы S3 и S4 стартуют после S1 и S2 (используют общий каркас и компонент дерева).
- Интегратор — ведущий: он сливает ветки в `main`, решает конфликты и объявляет «main зелёный».
  В 16:15 новые срезы не начинаем — только доводим начатое.
