# PROMPTS — журнал промптов (для ретроспективы)

Записывайте промпты, которые сработали ОЧЕНЬ хорошо или ОЧЕНЬ плохо. Это главный материал для ретро.
Заполняется по ходу дня, 1–2 минуты на запись.

## Шаблон записи
```
### [время] [имя] [срез Sx] — 👍 / 👎
Промпт: ...
Что ожидал: ...
Что получил: ...
Почему так вышло (контекст, размер задачи, неясность): ...
Что изменил / чему научился: ...
```

## Мини-статистика (в конце дня)
- Сколько раз откатывались через git: __
- Сколько раз запускали сабагентов и помогло ли: __
- Какой документ из docs/ оказался самым полезным: __
- Что сделали бы иначе в спецификации: __
