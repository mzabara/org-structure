# UI — как выглядит приложение

Язык интерфейса — русский. Дизайн — спокойный, деловой, много воздуха.

## Общий каркас
- Верхняя панель: название «Оргструктура», поле поиска по центру.
- Под ней вкладки: **«Подразделения»** и **«Сотрудники»** (два отдельных дерева).
- Слева/по центру — дерево, справа — панель деталей (карточка выбранного узла).
- На узких экранах панель деталей открывается поверх дерева.
- Базовые элементы (вкладки, поле поиска, кнопки, бейджи, подсказки, уведомления об ошибках) — компоненты Taiga UI 5. Дерево — собственный рекурсивный компонент.

## Дерево подразделений
- Узел = карточка: название, код мелким шрифтом, руководитель, бейдж «N сотр.».
- Кнопка ▸/▾ сворачивает ветку. По умолчанию раскрыты два верхних уровня.
- Клик по узлу — выбор, в панели справа показывается карточка отдела.

## Дерево сотрудников
- Узел = карточка: инициалы в круге, ФИО, должность, подпись с отделом.
- Линии связей — сплошные (линейное подчинение).
- У сотрудника с матричным подчинением — значок «пунктир» и подсказка «Матричные руководители: N».
  При выборе сотрудника его матричные руководители подсвечиваются пунктирной рамкой.
- Длинные ФИО и должности — перенос на 2–3 строки с многоточием, полный текст в `title`/подсказке.

## Карточка отдела (панель)
Название, код, описание; руководитель (ссылка на сотрудника); «Входит в» (ссылка на родителя);
«Дочерние подразделения» (ссылки); список сотрудников отдела
с переключателем «Включая вложенные подразделения»; каждый сотрудник — ссылка на его карточку.

## Карточка сотрудника (панель)
Инициалы, ФИО, должность, контакты; **отдел** (ссылка на карточку отдела);
«Линейный руководитель»; «Матричные руководители» (с комментарием «в рамках чего»);
«Подчинённые»; два блока: **«Чем занимается»** (задачи) и **«За что отвечает»** (зоны ответственности).
Пустые блоки показывают «Не указано», а не исчезают.

## Поиск
- Ввод от 2 символов, пауза 300 мс перед запросом.
- Выпадающий список двух групп: «Сотрудники», «Подразделения».
- Выбор результата: переключает на нужную вкладку, раскрывает путь до узла, выделяет узел и открывает карточку.

## Палитра и типографика
- Базовая тема — Taiga UI: её шрифт, отступы и палитра; свои стили вводим только для дерева и специфики карточек.
- Акцентный цвет — спокойный синий, задаётся через CSS-переменные темы Taiga UI; фон — светло-серый, карточки — белые.
- Цветовая кодировка отделов (если дойдём): 5–6 приглушённых оттенков; не передавать смысл только цветом.
- Доступность: контраст текста не ниже 4.5:1, управление с клавиатуры (Tab, Enter, стрелки для раскрытия).

## Палитра и типографика
- Системный шрифт (без внешних загрузок).
- Основной цвет — спокойный синий, фон — светло-серый, карточки — белые.
- Цветовая кодировка отделов (если дойдём): 5–6 приглушённых оттенков; не передавать смысл только цветом.
- Доступность: контраст текста не ниже 4.5:1, управление с клавиатуры (Tab, Enter, стрелки для раскрытия).
