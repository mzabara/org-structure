# DOMAIN — предметная область

## Термины
- **Подразделение (отдел)** — организационная единица. Образует дерево: у каждого, кроме корневого, есть родитель.
- **Сотрудник** — человек, закреплённый ровно за ОДНИМ подразделением (основное место работы).
- **Руководитель подразделения** — сотрудник, указанный как head подразделения. Обычно он находится в этом же подразделении.
- **Линейное подчинение (LINE)** — основной, административный руководитель. У каждого сотрудника, кроме главы компании, ровно один.
- **Матричное (пунктирное) подчинение (DOTTED)** — дополнительный руководитель по проекту или функции.
  У сотрудника может быть 0..N. Не заменяет линейного.
- **Задача (TASK)** — что сотрудник делает: «Разрабатывает REST API для оргструктуры».
- **Зона ответственности (RESPONSIBILITY)** — за что отвечает: «Отвечает за стабильность сервиса авторизации».

## Два дерева — не путать
| | Дерево подразделений | Дерево сотрудников |
|---|---|---|
| Узел | подразделение | сотрудник |
| Связь | `department.parent_id` | LINE-строка в `reporting_line` |
| Корень | единственное «Генеральная дирекция» | единственный сотрудник без LINE-руководителя |
| Пунктир | нет | DOTTED-связи (не образуют дерево, это дополнительные рёбра) |

Подразделение и сотрудник связаны: в подразделении видны его сотрудники,
у сотрудника виден его подразделение.

## Инварианты (должны соблюдаться всегда)
1. Ровно одно корневое подразделение (parent_id is null).
2. Ровно один сотрудник без LINE-руководителя.
3. У каждого остальных сотрудника ровно один LINE-руководитель.
4. Нет циклов: ни в дереве подразделений, ни в линейном подчинении.
5. Сотрудник не может быть своим руководителем (ни LINE, ни DOTTED).
6. Одна пара (сотрудник, руководитель) встречается не более одного раза.
7. DOTTED-руководитель может быть из любого подразделения.

## Крайние случаи, которые должны корректно отображаться
- Сотрудник без подчинённых (лист дерева).
- Сотрудник без задач и зон ответственности (пустое состояние).
- Очень длинные ФИО и должности (не ломают вёрстку).
- Подразделение без сотрудников (в данных не встречается, но UI не должен падать).
- Руководитель подразделения из другого подразделения (допустимо схемой, UI не должен падать).
- Сотрудник с несколькими матричными руководителями.
