# Frontend (Angular 22) — правила

Действуют правила корневого `AGENTS.md`, `docs/CODE-STYLE.md` и `docs/UI.md`.

- Каталог работы: только `frontend/`.
- Standalone-компоненты, signals, `@if`/`@for`, `inject()`. Никаких NgModules и `*ngIf`/`*ngFor`.
- Базовые UI-элементы — из Taiga UI 5 (кнопки, поля, вкладки, бейджи, подсказки, уведомления, скелетоны). Свои аналоги не создаём. Дерево — собственный компонент в `shared/`: в Taiga UI нет древовидного компонента.
- Типы API генерируются из `docs/openapi.yaml` (каталог `src/app/core/api/`), вручную не дублируются.
- Вызовы API идут через `/api/v1` (dev-прокси на `localhost:8080`).
- Тексты интерфейса — на русском. Комментарии/TSDoc — на русском.
- Новые npm-зависимости — только по согласованию.
- Команды: `npm start`, `npm run build`, `npm test`.
- Не уверен в API Angular 22 — проверь документацию angular.dev, не выдумывай.
