# Оргструктура

Учебный проект Vibecoding Day. Участники самостоятельно формируют
требования, спецификацию, архитектурные решения и план реализации.
Не создавай эти материалы и не реализуй функции без соответствующей задачи.

## Технологический ориентир

- Frontend: Angular 22, Taiga UI 5, TypeScript, SCSS.
- Backend: Kotlin, Spring Boot, JDK 21, Gradle Kotlin DSL.
- База данных: PostgreSQL, миграции Flyway.
- Только синтетические данные, без реальных персональных данных и секретов.

## Работа

- Изучи текущее состояние репозитория перед изменениями.
- При неясных требованиях уточняй, не придумывай за участников.
- Сначала предложи небольшой план и дождись согласования,
  если выполнение уже явно не одобрено.
- Делай только запрошенное, сохраняй чужие изменения.
- Предпочитай простые решения и существующие соглашения проекта.
- Добавляй зависимости только при необходимости.

## Проверка

- Проверяй изменения сборкой, тестами и проверкой типов, где применимо.
- Осматривай diff и запускай `git diff --check`.
- Не выдавай непроверенный результат за готовый; сообщай о блокерах.
- Commit и push выполняй только по явной просьбе.
